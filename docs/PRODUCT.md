# 在一起 · 第一版产品与验收说明

## 核心流程

1. 首页看示例 → ChatGPT 登录 → 上传 JPG / PNG / WebP，单张不超过20MB。
2. 照片池选择最多6张参考图 → 现有合影加人 / 全新合影 / 虚拟旅行 / 自然修饰 → 设置衣着、背景、站位、风格和补充描述 → 确认照片使用权 → 生成。
3. 初次成功消耗1个任务额度，包含最多3次成功出图。技术失败不扣成功次数。创作记录保留各版本，用户/家属自行验收人物相似度。
4. 照片池多选 → 主题、标题、扉页文字、顺序、每页说明 → 保存为私密相册。
5. 仿真翻书 / 渐隐 / 横向滑动 / 慢镜。PageFlip 负责连续拖动、软页裁切、阴影、双面不同页面与手机触控；手机实际性能必须通过真实设备进一步评估，不能仅以库的功能宣称已验收。
6. PDF通用保存、原片ZIP；珍藏权益提供内嵌图片和翻页引擎的单文件离线HTML、浏览器WebCodecs编码的MP4。
7. 私密 / 带可选密码的链接分享 / 主动公开到广场。点赞、1—5星评分和评论要求登录。
8. 取消分享即撤销旧链接；单张删除同步移除相册对应页；整本删除保留照片池；全部删除清空作品、创作记录和社交记录，交易订单单独保留。

## 提示词策略

实现在 `lib/prompts.ts`。基础指令保留可辨识面容、年龄、肤质和体型，不混合人物身份。合影模式明确第1张为基础图，其余为待加入人物参考，保护现有人物。全新合影要求每个独立人物均出现。虚拟旅行保持人物身份，匹配景观透视。照片优化仅修改指定区域，默认保留年龄。修改意见作为下一次指令附加，仍以原始参考照为身份锚点。

合影质量不能由代码保证；上线后需要用获授权的真实照片，按相似度、原人物保持、手部、光线、遮挡、站位、家属认可度建立样本验收。本站生成内容显示AI标识，原片下载再传播需用户保留AI说明。

## 安全与一致性

- 访问身份由Sites托管认证注入，生产代码没有本地模拟用户后门。
- 个人资源在服务端检查owner；公开图片仍需有效相册token及访问密码会话。
- 写请求校验同源。解锁、上传、生成、社交和下单限流。
- 相册修改比较revision，防止多窗口覆盖；分享取消清理密码会话。
- 生成任务加锁；预留额度状态和5分钟失联恢复避免一直占用额度。删除作品后迟到的AI结果不会再次插入照片池。
- 支付核对RSA签名、商户、金额、币种、订单与唯一交易号；事务中到账，重复通知不重复发放。
- 前端只用React文本或textContent显示用户内容；离线导出转义标题、字幕。

本地接口自动验收和内存支付测试不等同于真实API、商户付款及手机性能验收。真实AI密钥、微信/支付宝商户密钥尚未配置。浏览器和生产验收结果见交付时的 `docs/VALIDATION.md`。
